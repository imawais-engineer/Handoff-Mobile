# HANDOFF-MOB — Complete Push & Build Guide

This guide walks you through: cloning the empty GitHub repo, filling it with
the required files, pushing, and getting your finished APK.

Total time: about 10 minutes of your time, plus 10-20 minutes of
GitHub building automatically.

---

## What you need

- The **HANDOFF-MOB.zip** file (downloaded from this project, ~98 KB)
- **Git** installed on your computer — check by opening a terminal and
  typing `git --version`. If it's missing, install from
  https://git-scm.com/downloads
- A **GitHub Personal Access Token** (Git asks for it instead of your
  password):
  1. Go to https://github.com/settings/tokens
  2. "Generate new token (classic)" -> tick the **repo** checkbox ->
     Generate
  3. Copy the token now (you won't see it again)

---

## Step 1 — Unzip and enter the folder

Unzip HANDOFF-MOB.zip somewhere easy, then open a terminal in that folder:

```bash
cd path/to/HANDOFF-MOB
ls
```

You should see: `app/  gradle/  .github/  build.gradle.kts
settings.gradle.kts  gradle.properties  gradlew  README.md  .gitignore`

> These ARE the required files. Everything else (APK, build outputs) is
> generated by GitHub for you — you never upload those.

## Step 2 — Connect to your new empty repo

```bash
git init
git add .
git commit -m "Handoff Mobile: complete Android app + APK build recipe"
git branch -M main
git remote add origin https://github.com/imawais-engineer/HANDOFF-MOB.git
git push -u origin main
```

When asked to log in: username is `imawais-engineer`, and paste the
**Personal Access Token** as the password.

> If `git push` complains "remote contains work", run
> `git push -u origin main --force` — safe here because the repo is empty.

## Step 3 — Watch GitHub build the APK

1. Open https://github.com/imawais-engineer/HANDOFF-MOB/actions
2. A run called **"Build Android APK"** should already be running
   (yellow dot). If not: Actions tab -> "Build Android APK" ->
   "Run workflow" -> Run.
3. Wait 10-20 minutes. The dot turns **green** when done.
4. Click the finished run -> scroll down to **Artifacts** ->
   download **HandoffFiles-debug-apk**. That's your APK.

## Step 4 — Install on your phone

- Download the artifact zip on your phone, unzip it to get `app-debug.apk`
- Tap the APK -> allow "install from unknown sources" if asked
- Open the app: Home -> Send / Receive / History / Settings

Quick sanity test: in the app open **Receive Files -> Start Web Mode**,
note the URL and 6-digit PIN shown, then from any computer on the same
Wi-Fi open that URL in a browser, enter the PIN, and send a small file.

## If the build fails

- Open the failed run in the Actions tab, click the red step to expand the
  log, and copy the last ~20 lines of error text
- Most common causes:
  - **"SDK location not found"** — a `local.properties` file snuck into the
    repo. Delete it (the workflow also removes it automatically)
  - **"gradlew: Permission denied"** — the workflow already runs
    `chmod +x gradlew`, so this shouldn't happen, but re-pushing the file
    fixes it
  - **Dependency download errors** — just click "Re-run jobs" once;
    transient network hiccups are common

## Rebuilding after changes

Whenever you change any Kotlin file, repeat:

```bash
git add .
git commit -m "describe your change"
git push
```

GitHub rebuilds the APK automatically. Latest artifact is always on the
most recent green run.

## Reference — what each required file is for

| File / folder            | Purpose                                        |
|--------------------------|------------------------------------------------|
| `app/src/main/java/...`  | The app: protocol, crypto, transfer, UI screens|
| `app/src/test/`          | Unit tests (run during the GitHub build)       |
| `app/build.gradle.kts`   | App build settings (SDK versions, dependencies)|
| `build.gradle.kts`       | Project-level build settings                   |
| `settings.gradle.kts`    | Tells Gradle the `app` module exists           |
| `gradle/libs.versions.toml` | Version catalog for all libraries           |
| `gradle/wrapper/*`       | Auto-downloads the exact Gradle version needed |
| `gradlew`                | Launch script the workflow executes            |
| `.github/workflows/build-apk.yml` | The build recipe GitHub follows       |
| `.gitignore`             | Keeps build junk out of the repo               |
| `README.md`              | Project docs (safe to edit freely)             |
